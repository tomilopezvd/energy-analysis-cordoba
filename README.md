# ⚡ Análisis del consumo energético en Córdoba

Proyecto de análisis y predicción del consumo energético en Córdoba utilizando Python.

## 📊 Descripción

Se analizan datos de consumo eléctrico en Argentina y su aplicación a Córdoba, incluyendo proyección de demanda energética y participación de energías renovables.

## 🧠 Tecnologías

- Python  
- Pandas  
- Matplotlib  
- Scikit-learn  

## 📈 Resultados

- Tendencia creciente del consumo energético  
- Proyección de aumento de la demanda  
- Estimación de consumo en Córdoba para 2026  
- Participación de energías renovables  

## ⚡ Enfoque en Córdoba

Se realizó una adaptación del modelo para estimar el consumo energético en Córdoba Capital, considerando crecimiento y transición energética.

## 🎯 Objetivo

Desarrollar habilidades en análisis de datos aplicadas al sector energético.
